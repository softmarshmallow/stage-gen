# Concept gallery

This directory contains selected game concepts that passed the repository's generated-media
publication gates. Each concept package keeps its readable `concept.md`, one reviewed cover image,
portable provenance, an independent visual-review report, and an artifact-specific rights notice.

The ignored working handoff remains the full `images/cover.png`. A gallery may use a smaller
`images/cover.webp` preview when the deterministic publication transform is recorded and the exact
preview bytes receive a new independent review; that preview does not replace the full workspace
handoff.

Exploratory candidates belong under the ignored `concept-studio/workspaces/` tree, never here.
