# Canonical content library

This directory holds repository-owned canonical subjects and their curated
representations for documentation, demonstrations, and asset pipelines. The
library owns each subject's profile and original artwork.

Content is organized by subject type, starting with [characters](characters/README.md).
Other categories can be added when their first entries are ready. Executable
examples and generated run output remain with their existing owners.

Today, the library contains [Nami](characters/nami/README.md), the repository
mascot, and [Riko](characters/riko/README.md), an adult human woman with exaggerated
hourglass proportions. Nami has two illustration poses and detailed and flat SD
concepts; Riko has fitted and loose sweater illustrations and a flat SD concept.
The library retains distinct useful styles; consumers select the named
representation suited to their purpose.
Pipeline integration and broader user documentation updates are deferred.
