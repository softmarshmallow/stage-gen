# Request ledger

Updated: 2026-09-11. Scope: the standalone experimental Godot project in Git;
it retains the spike's experimental purpose.

This is a history of requests and outcomes at each pass, not the current TODO
list. Later-resolution references explain where an earlier pending state or
implementation was superseded. Budget figures are snapshots for their recorded
passes. [CURRENT_STATUS.md](CURRENT_STATUS.md) owns the current implemented
inventory, remaining work, and distinctions between deferred requests and
optional ideas.

Working terminology, topology, internal component reuse, and the separate
Presentation Lab have been introduced. They do not ratify upstream modules or
contracts; production promotion or replacement has not happened.
[P106's SDK design](../../../../docs/research/game-presentation-sdk-design.md) now owns the
proposed successor taxonomy/topology; its [triage](../../../../docs/research/game-presentation-sdk-triage.md)
accounts for every P01–P106 record. The implemented tree is still unchanged.
[USER_PROMPTS.md](USER_PROMPTS.md) preserves request wording with recorded
formatting normalization, including corrections and scope decisions. IDs follow
conversation order, not architecture.
