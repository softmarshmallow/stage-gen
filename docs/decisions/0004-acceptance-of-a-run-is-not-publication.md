# 0004 — Acceptance of a run is not authorization to publish

*Ruled 2026-09-01.*

## Fact

The twelve expression plates, three backdrops and three music tracks in `out/larkfield/`, and
the visual novel's play, were independently reviewed on 2026-09-01 by the task owner. The
producer did not give that review.

## Challenge

An accepted run is reviewed bytes with a named reviewer; treating acceptance as sufficient for
publication would remove a step that has already done its work.

## Ruling

The review covers acceptance of the run in `out/larkfield` only. Publication stays a separate
authorization, requested for the exact reviewed bytes. The two gates answer different
questions: acceptance asks whether the artwork is right, publication asks whether the
repository may redistribute it.

## Evidence

The generated-media publication gate is a distinct check with its own inventory and rights
records; nothing in it reads a semantic-review verdict.

## Falsifier

A publication policy under which a named non-producer semantic review is by itself a
sufficient rights basis — which would make the second gate ceremonial.
