# 0048 — The concept sheet has no rear view, and that is a contract gap rather than an equipment fix

*Ruled after a four-strip spike.*

## Fact

The prepared concept prompt asks for exactly two views — one complete side-view game-scale
figure and one front-three-quarter identity view — and that string has been unchanged since the
first prepared commit, so the prepared path has never rendered the back of any actor. That same
sheet is the only reference every later atlas receives, while the concept prompt calls itself
the strict identity source for all later motion and dialogue atlases. The player's climb states
are declared rear-facing, so the states whose artwork is entirely back-facing are extrapolated
from a sheet with no rear information at all.

## Challenge

The visible symptom is equipment drift — a sword that survives one strip and not the next — so
the obvious reading is that a rear view is the fix for it.

## Ruling

It is not. Supplying a faked rear view as a second reference did not improve drift in a
four-strip spike: the sword survived one of two strips generated from the concept alone, and
neither of two generated with the rear view added. So this is closed as the contract gap it is
— either give the prepared sheet a rear view, or stop declaring states rear-facing — and
equipment is gated separately. Landing it re-digests the concept node and invalidates the whole
player fan-out, roughly twelve provider images, so it is sequenced before any other player
regeneration rather than paid twice.

## Evidence

The legacy path did render front, side and back and appended a structured proportion clause;
the prepared path dropped both and relies instead on a proportion phrase duplicated by hand
into the style keywords, with nothing keeping it in sync with the structured field. The back of
the costume, the hang of the satchel, and whether the sword reads from behind have never been
authored, generated or reviewed anywhere.

## Falsifier

A spike in which a *real* reviewed rear view — not a faked one — measurably reduces equipment
drift, which would make the rear view an equipment fix after all.
