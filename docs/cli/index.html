Stage Gen/Docs/CLI reference

CLI reference

Plan, run and inspect asset workflows and your own SDK pipelines

stage-gen [-h] COMMAND ...

Written from the parser itself when the site is built. stage-gen <command> --help prints the same for one command.

  • list: list the installed workflows
  • show: one workflow: steps, sample plan, examples
  • plan: plan a workflow offline, before any spend
  • run: run a workflow; provider calls need its explicit opt-in
  • inspect: read, verify or write the view of one run folder
  • view: open the local viewer over run folders
  • example: verify or promote pinned examples
  • catalog: export the catalog of installed workflows and their examples
  • capability: one provider or media call outside any graph
  • models: inspect the application-owned route catalog
  • env: import provider keys into a local dotenv file

Movie sprite: One character picture in. A transparent idle loop out.

stage-gen plan movie-sprite [-h] --input INPUT_ROOT
                            (--authoring AUTHORING | --source SOURCE)
                            [--source-provenance SOURCE_PROVENANCE] --finish FINISH
                            --output OUTPUT_ROOT
                            [--target {prepare,generate,adopt,finish}]
                            [--resolution {360p,720p,1080p,4k}]
                            [--aspect-ratio {9:16,16:9}] [--duration DURATION]
                            [--candidate CANDIDATE]
ArgumentMeaning
--input INPUT_ROOTFolder the input refs resolve in Required.
--authoring AUTHORINGInput-relative JSON: canonical_image and optional prompts
--source SOURCEInput-relative supplied MP4 or transparent Matroska
--source-provenance SOURCE_PROVENANCEOptional original sidecar, relative to inputs
--finish FINISHInput-relative finishing JSON Required.
--output OUTPUT_ROOTRun folder to write Required.
--target {prepare,generate,adopt,finish}The last step to plan or run One of: prepare, generate, adopt, finish. Default: finish.
--resolution {360p,720p,1080p,4k}Resolution of the generated take One of: 360p, 720p, 1080p, 4k. Default: 720p.
--aspect-ratio {9:16,16:9}Aspect ratio of the generated take One of: 9:16, 16:9. Default: 9:16.
--duration DURATIONSeconds of the generated take Default: 8.
--candidate CANDIDATEDistinct identity for a deliberate new draw Default: take-01.

stage-gen example promote

export runs as a draft example and pin it in workflow.toml

stage-gen example promote [-h] --run RUNS --id EXAMPLE_ID [--title TITLE]
                          [--option KEY=VALUE] [--examples EXAMPLES_DIR]
                          workflow
ArgumentMeaning
workflowthe workflow id the example belongs to
--run RUNSa run folder to export; repeatable Required.
--id EXAMPLE_IDthe new example's id Required.
--title TITLEthe example's name (default: from its id)
--option KEY=VALUEan importer option, such as input_root=DIR, the folder the run was given as --input Repeatable.
--examples EXAMPLES_DIRthe example store
