Universe

A poster, a synopsis and a direction in. A reviewed storyworld and one concept image per entity out.

universe · Page · Contract

A semantic phase proposes typed entities, their relationships and open questions, which an independent reviewer must admit; a gallery phase then draws exactly one reviewed concept image for each admitted entity.

Steps

StepNode types
Read the source
The poster, synopsis and expansion direction are locked by digest and kept apart: the poster is visual evidence only, the synopsis holds the world's facts.
Lock the source and its evidence universe/source.lock
Propose and plan
A language model proposes typed entities, their relationships and the questions the source leaves open, then plans one concept image per entity.
Propose the universe universe/universe.propose
Plan the gallery universe/gallery.plan
Review and admit
The proposal is checked deterministically, then reviewed by a model that did not write it. Only an admitted world reaches the gallery phase.
Evaluate the proposal universe/universe.evaluate
Review the world independently universe/universe.review
Admit the world universe/universe.admit
Direct
One visual grammar is set for the whole set, then a direction for each entity.
Set the visual grammar universe/direction.global
Direct one entity's concept universe/direction.entity
Draw and review
Each entity gets exactly one concept image, reviewed on a smaller copy by a model that did not draw it.
Draw the concept image universe/concept.image
Make a review copy universe/concept.proxy
Review the image independently universe/concept.review
Close
Each entity's text record is written, and the gallery closes with every image's status recorded.
Write the entity record universe/entity.record
Close the gallery universe/gallery.close

Outputs

semantic/universe.jsonThe admitted storyworld: entities, relationships and open questions
semantic/admission.jsonWhy the world was admitted, with the review it passed
