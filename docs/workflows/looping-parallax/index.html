Looping parallax

Layer pictures in. Repeating layers and their scroll placement out.

looping-parallax · Page · Contract

Each supplied layer is made to repeat on its own, by mirroring its edges or by repainting the seam, then the layers are composed with their offsets and scroll factors into a portable manifest and a preview frame.

Steps

StepNode types
Make each layer repeat
Each supplied layer is prepared on its own. By default its repeating edges are mirrored, so the repeat is exact; a seam layer that does not already loop has the cut repainted instead.
Make the layer repeat parallax.prepare_layer
Repaint the seam parallax.repaint_layer
Compose
The prepared layers are placed with their offsets and scroll factors, and a preview frame is drawn. Changing placement reruns only this step.
Compose the scrolling background parallax.compose

Outputs

parallax/manifest.jsonEvery layer with its size, order, offsets, repeat axes and scroll factor
parallax/preview.pngOne composed frame, for inspection

Try it

Two original layers and their parallax.json, written by uv run python src/stage_gen/workflows/looping_parallax/inputs/supplied_layers/make_inputs.py out/looping-parallax-input

stage-gen plan looping-parallax --input out/looping-parallax-input

stage-gen run looping-parallax --input out/looping-parallax-input --output out/looping-parallax-try --cache-dir out/cache

stage-gen inspect out/looping-parallax-try --verify
