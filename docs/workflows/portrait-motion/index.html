Portrait motion

One finished sprite in. Eyes and mouth a game can drive separately out.

portrait-motion · Page · Contract

The face is found and cropped, a reviewer decides which eyes and mouth can safely change, and an image model draws every new state in one sheet. Each drawing is aligned to the original, every combination is reviewed, and the accepted patches go back on the sprite at full size.

Steps

StepNode types
Find the face
A vision model returns only a box around the face. The workspace is cut from the full sprite with padding on every side.
Find the face 2d/portrait_motion/face_location
Decide and draw
A reviewer decides which eyes and mouth can safely change. The image model then draws every new state in one sheet, so they share one hand.
Decide what can move 2d/portrait_motion/admission
Lay out the sheet 2d/portrait_motion/guide
Draw the new states 2d/portrait_motion/atlas
Fit
Each new drawing is aligned to the original, and one that moved or changed scale is refused. A vision model outlines the eyes and mouth that may change.
Line them up 2d/portrait_motion/registration
Outline eyes and mouth 2d/portrait_motion/geometry
Compose and review
Every eyes-and-mouth combination is built from those outlines, then judged by a reviewer that did not draw them.
Build every combination 2d/portrait_motion/composition
Review the result 2d/portrait_motion/quality
Deliver
Only accepted features are kept. The patches go back on the original sprite at full size, and every pixel outside them is checked unchanged.
Keep what passed 2d/portrait_motion/terminal

Outputs

render/animation.webpA preview at the sprite's full size, playing the timeline
render/states/Every eyes-and-mouth combination, as full-size PNGs
render/patches/Each eye and the mouth in every state, as patches placed at one offset
render/manifest.jsonWhere the patches go, which feature each belongs to, and a sample timeline

Try it

Your own finished sprite PNG with its provenance sidecar; the face spec is the committed inputs/face-four-card.json. The run step is paid: it needs your provider keys (or --dotenv)

stage-gen plan portrait-motion --source sprite.png --spec src/stage_gen/workflows/portrait_motion/inputs/face-four-card.json --run out/portrait-try --face-crop

STAGE_GEN_RUN_LIVE=1 stage-gen run portrait-motion --run out/portrait-try --live

stage-gen inspect out/portrait-try --verify
