Movie sprite

One character picture in. A transparent idle loop out.

movie-sprite · Page · Contract

The picture is fitted on a green plate and sent once to a video model, with the same picture at both ends. The take you choose is finished locally: keyed to transparency, the face held still so blinks and mouth shapes can be added separately, the loop closed, and every frame checked.

Steps

StepNode types
Prepare
The picture is fitted onto a green plate, and the request is checked against the video route's limits before anything is paid for.
Fit onto a green plate movie_sprite.prepare
Generate
One video call animates the same picture at both ends of an eight-second take. A new take is a deliberate new draw, never a silent retry.
Generate a take movie_sprite.generate
Finish
You pick the take. Finishing runs locally and costs nothing: green is removed, the face is held to the first frame, the loop is closed and every frame is verified.
Adopt the chosen take movie_sprite.adopt
Key, loop and verify movie_sprite.finish

Try it

A synthetic transparent clip and finish.json, written by uv run python src/stage_gen/workflows/movie_sprite/inputs/supplied_clip/make_inputs.py out/movie-sprite-input (needs FFmpeg)

stage-gen plan movie-sprite --input out/movie-sprite-input --source actor.mkv --finish finish.json --output out/movie-sprite-plan

stage-gen run movie-sprite --input out/movie-sprite-input --source actor.mkv --finish finish.json --output out/movie-sprite-try --cache-dir out/cache

stage-gen inspect out/movie-sprite-try
