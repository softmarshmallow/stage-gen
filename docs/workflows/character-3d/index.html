3D character

One written brief in. One rigged, reviewed character out.

character-3d · Page · Contract

An agent draws reference views, a 3D service builds a textured mesh from them, and the mesh is stood upright, rigged and given test clips. Independent reviewers judge every stage on renders in the export's own finish, and the export is admitted only when numbers and pictures both pass.

Steps

StepNode types
Before any spend
Blender's required features and the brief are checked offline. Nothing is paid for until both pass.
Probe Blender 3d/character/runtime_admit
Check the brief 3d/character/brief_preflight
Reference sheet
An agent draws a canonical sheet, then the front and back views the mesh service needs. A reviewer that did not draw them admits the bundle. Round two runs only after a refusal.
Draw references 3d/character/reference_agent
Review references 3d/character/reference_review
Admit references 3d/character/references_admit
Textured mesh
Tripo builds one textured character from the views. The worker normalises it and renders five views in the matte finish the export will wear. Supplied part meshes are converted and measured as they arrived.
Generate mesh 3d/character/generate_part
Measure the part 3d/character/normalize
Review mesh 3d/character/part_review
Admit mesh 3d/character/part_admit
Admit parts 3d/character/parts_admit
Orientation
The mesh is stood on the ground plane facing forward, measured, and reviewed again. Without review, the exported assembly is selected instead.
Orient and ground 3d/character/assemble_agent
Review orientation 3d/character/assembly_review
Admit orientation 3d/character/assembly_admit
Select the assembly 3d/character/assembly_select
Skeleton and clips
Tripo adds bones and weights, or an agent locates the joints and binds the skin. The worker proves the rigged mesh is still the admitted mesh, bakes diagnostic clips and exports at profile height. A rig-only run starts from an admitted assembly, verified and measured first.
Adopt the admitted assembly 3d/character/adopt_assembly
Submit for rigging 3d/character/provider_rig_submit
Collect and audit rig 3d/character/provider_rig_collect
Build the rig 3d/character/rig_agent
Review rig 3d/character/rig_review
Bounded recovery
If the rig is refused, the mesh is regenerated once from the same references and rigged again. A second refusal ends the run with both verdicts on record.
Regenerate mesh 3d/character/regenerate_whole
Review mesh 3d/character/recovery_part_review
Admit mesh 3d/character/recovery_part_admit
Orient and ground 3d/character/recovery_assemble
Review orientation 3d/character/recovery_assembly_review
Admit orientation 3d/character/recovery_assembly_admit
Admission
Numbers and pictures must both pass. A good picture cannot waive a numeric failure; a clean report cannot waive a visible one. A run without review selects the intact export instead.
Admit export 3d/character/rig_admit
Select the export 3d/character/rig_select

Try it

An original character brief as an experiment JSON beside its inputs, and a Blender install

stage-gen run character-3d --experiment characters/my_character_01.json --input-root characters --run-root out/character-try --blender /Applications/Blender.app/Contents/MacOS/Blender --admission-mode development --prepare-only

stage-gen inspect out/character-try
